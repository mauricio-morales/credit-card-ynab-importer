# Implementation Plan: QIF Export Alongside YNAB CSV Output

**Branch**: `005-qif-export` | **Date**: 2026-08-09 | **Spec**: [spec.md](./spec.md)
**Input**: Feature specification from `/specs/005-qif-export/spec.md`

## Summary

For the BAC and DaviBank/Scotia pipelines, generate a `.qif` file alongside
every final `out3` YNAB CSV file (one per currency split), so transactions
can be imported into any QIF-compatible finance tool with no extra step.
QIF generation is a post-processing conversion of the already-written out3
CSV file — a new stdlib-only module `scripts/qif_export.py` reads the
finished CSV and writes a sibling `!Type:Bank` QIF file with one record per
CSV row (date reformatted to `MM/DD/YYYY`, memo line omitted when empty,
amount copied verbatim to reuse the existing sign convention, embedded
newlines in payee/memo neutralized). `orchestrator.py` calls it once per
currency split immediately after each `out3` CSV is written; `bac_stage3.py`
and `davi_stage3.py` are untouched, guaranteeing zero regression to existing
CSV output.

**Target Platform**: macOS CLI/TUI (existing `scripts/orchestrator.py` + `tui/` Textual app)
**Project Type**: Single project (existing `scripts/` pipeline stages + `tui/` Textual UI + `tests/`)
**Performance Goals**: N/A — statements are tens to low hundreds of rows; sub-second, unchanged order of magnitude from existing stages
**Constraints**: Zero change to existing `out3` CSV content, format, or naming (Constitution Principle II, IV; FR-010); QIF generation always-on, no new CLI flag (spec Assumptions); QIF derived strictly from the finished CSV, not from raw/intermediate pipeline data (research.md §4)
**Scale/Scope**: Single-user personal finance tool; both existing bank pipelines (BAC, DaviBank/Scotia) affected identically via a single shared converter module

| IV. Data Fidelity | ✅ PASS | QIF rows are derived 1:1 from already-fidelity-checked CSV rows: same amounts (verbatim sign reuse, research.md §3), same row order, same payee/memo text (only newline neutralization per FR-012, research.md §5).
